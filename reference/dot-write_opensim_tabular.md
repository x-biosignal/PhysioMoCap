# Internal writer for tab-separated OpenSim files (MOT/STO)

Internal writer for tab-separated OpenSim files (MOT/STO)

## Usage

``` r
.write_opensim_tabular(x, path, format = c("mot", "sto"))
```

## Arguments

- x:

  A PhysioExperiment.

- path:

  Output path.

- format:

  Either `"mot"` or `"sto"`.

## Value

`path`, invisibly.
