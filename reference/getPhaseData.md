# Get data for all phases as a list of matrices

Get data for all phases as a list of matrices

## Usage

``` r
getPhaseData(x, include_subphases = FALSE)
```

## Arguments

- x:

  A segmented_phases object

- include_subphases:

  Whether to include subphases

## Value

Named list of matrices

## References

Winter DA (2009). "Biomechanics and Motor Control of Human Movement."
4th ed. Wiley.

## See also

[`segmentPhases()`](https://x-biosignal.github.io/PhysioMoCap/reference/segmentPhases.md),
[`extractPhase()`](https://x-biosignal.github.io/PhysioMoCap/reference/extractPhase.md),
[`hasValidPhases()`](https://x-biosignal.github.io/PhysioMoCap/reference/hasValidPhases.md)

  confidence = rep(1, 6), stringsAsFactors = FALSE)
