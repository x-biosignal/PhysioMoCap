# Print a multi-plate forceplate analysis summary

Print a multi-plate forceplate analysis summary

## Usage

``` r
# S3 method for class 'forceplate_analysis_multi'
print(x, ...)
```

## Arguments

- x:

  A `forceplate_analysis_multi` object.

- ...:

  Additional arguments (ignored).

## Value

Invisibly returns `x`.
