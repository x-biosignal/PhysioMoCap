# Get an event by name from a TaskSchema

Get an event by name from a TaskSchema

## Usage

``` r
getEvent(schema, event_name)
```

## Arguments

- schema:

  A TaskSchema object

- event_name:

  Name of the event to retrieve

## Value

An Event object or NULL if not found

## References

Winter DA (2009). "Biomechanics and Motor Control of Human Movement."
4th ed. Wiley.
