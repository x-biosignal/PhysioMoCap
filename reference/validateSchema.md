# Validate a TaskSchema

Checks that a TaskSchema is internally consistent.

## Usage

``` r
validateSchema(schema)
```

## Arguments

- schema:

  A TaskSchema object

## Value

TRUE if valid, otherwise throws an error

## References

Winter DA (2009). "Biomechanics and Motor Control of Human Movement."
4th ed. Wiley.
