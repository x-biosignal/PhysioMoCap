# Get event names from a TaskSchema

Get event names from a TaskSchema

## Usage

``` r
getEventNames(schema)
```

## Arguments

- schema:

  A TaskSchema object

## Value

Character vector of event names

## References

Winter DA (2009). "Biomechanics and Motor Control of Human Movement."
4th ed. Wiley.
